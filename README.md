# MJI Capital Growth Scope

Static proposal page for MJI Capital Phase 2, prepared by EZZEY.

## Structure
- `index.html`: the full page (inline CSS, Google Fonts only)
- `vercel.json`: static hosting config with noindex and security headers

## Deploy on Vercel
1. Import this repo in Vercel (company-owned account).
2. Framework preset: Other. No build command. Output directory: root.
3. Every push to the production branch redeploys.

## Local preview
`npx serve .` or open `index.html` in a browser.
